# AsteriskCraft — enemy Zerg build order.

# Lines run top-to-bottom. Edit this file (or override it from your own datapack at
# data/<namespace>/build_scripts/zerg.txt) and run /reload to change how the enemy plays.
#
# Commands:
#   Workers: N            keep at least N drones alive from here on (trains more when short)
#   Defence: <units>      train these units; they patrol and defend the base
#   Wave: <units>         train these units, then send the whole group to attack once complete
#   Wait S                pause S seconds before the next command
#   Repeat N              loop the previous N commands endlessly (put it last)
#
#   <units> = comma list of "Qty Unit", e.g. "3 Zergling, 1 Hydralisk". Qty may be a range "3-5".
#   Units: Zergling (melee), Hydralisk (ranged), Mutalisk (air), Ultralisk (heavy melee),
#          Drone (worker).
#
# The AI waits until it can afford each unit, so a wave only leaves once fully trained. Each unit
# also takes its own build time — an Ultralisk alone is a minute — so adding one lengthens a wave.
