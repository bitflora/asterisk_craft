# AsteriskCraft — enemy Terran build order.
#
# Lines run top-to-bottom. Edit this file (or override it from your own datapack at
# data/<namespace>/build_scripts/terran.txt) and run /reload to change how the enemy plays.
#
# Commands:
#   Workers: N            keep at least N SCVs alive from here on (trains more when short)
#   Defence: <units>      train these units; they patrol and defend the base
#   Wave: <units>         train these units, then send the whole group to attack once complete
#   Wait S                pause S seconds before the next command
#   Repeat N              loop the previous N commands endlessly (put it last)
#
#   <units> = comma list of "Qty Unit", e.g. "3 Marine". Qty may be a range "3-5".
#   Units: Marine (ranged infantry), SCV (worker). That is the whole Terran roster today.
#
# The Terran push with counts rather than with variety. A Marine is the cheapest combat unit in the
# mod, comes out in 24 seconds, and dies to almost anything on its own — so the waves below grow in
# size where the Zerg script grows in kind, and the interval between them is what the human is
# actually racing.
#
# Two Marines are already standing on every Command Center at world start (RaceProfile.baseDefences),
# so the opening Defence below is reinforcement, not the first guard.
#
# The AI waits until it can afford each unit, so a wave only leaves once fully trained.

Workers: 9

# Opening: post a squad while the economy ramps up.
Defence: 3 Marine
Wait 70

# Escalating pushes. The first one is small enough to be turned away by a Zealot or a Sunken; by the
# third, massed rifles out-range anything melee and the answer has to be static defence or numbers.
Wave: 4 Marine
Wait 170
Wave: 6 Marine
Wait 200

Defence: 2 Marine
Wave: 8-10 Marine
Wait 200

# Endless massed pushes from here on. Note what the race still cannot do: nothing here detects, so a
# Dark Templar or a burrowed Lurker walks through a Terran army untouched, and nothing here shoots
# down a Mutalisk that stays high. Those are real holes in the roster, deliberately left standing
# until the race has more in it.
Wave: 10-14 Marine
Wait 220
Repeat 2
